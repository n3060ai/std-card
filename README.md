# 学生証メーカー

キャラクターの顔写真を枠に合わせて配置し、学校名や氏名などを入力して、学生証風のPNG画像を作れるWebツールです。
HTMLファイル1つで動作し、画像はブラウザ内だけで処理されます(サーバーへ送信されません)。

## 使い方

1. 「基本」タブで顔写真を選び、学校名・氏名などを入力します。
2. 写真の位置は、プレビュー上をドラッグして調整します。拡大縮小は、マウスホイールまたはスライダーで行います。
3. 「デザイン」タブでレイアウトや配色を選びます。
4. 必要なら「校章・印」タブで校章や判子を追加し、ドラッグで好きな位置に動かします。
5. 「PNGを作成」を押すと画像が表示されます。自動で保存されない場合は、画像を長押し(PCは右クリック)して保存してください。

## 機能

### 基本タブ
- 顔写真のアップロード、位置・拡大率の調整
- 学校名、氏名、ふりがな/ローマ字、学年・クラス、生年月日、学籍番号、発行日、証明文、証の名称
- 空欄にした項目は表示されません
- 🎲ボタンで、生年月日・学籍番号・発行日をランダム入力
- 学籍番号の形式は4種類(英字+数字 / 年度+連番 / 数字のみ / 一部だけXX)

### デザインタブ
- 文字レイアウト5種類
  - A:写真左・上帯
  - B:写真右・上帯
  - C:写真左・下帯
  - D:帯なし(線のみ)
  - E:学生証風(英字併記・校長印)
- 写真サイズ(標準 / 大きめ / 特大)
- 区切り線(なし / 氏名の下 / 全項目 / 全項目の点線)
- 証明文の配置(左寄せ / 中央 / 右寄せ / 幅いっぱい)
- 配色プリセット5種類(さくら、ワイン、オレンジ、ネイビー、スカイ)と、帯・背景・アクセントの3色の個別指定
- レイアウトE用の、英字サブタイトルと透かし文字

### 校章・印タブ
- 校章:盾 / 二重円 / 花 / 星(中の1文字を指定可)、または自分の画像
- 印:四角 / 丸 / 二重丸(4字まで)、または自分の画像
- どちらもドラッグで移動、スライダーで大きさ変更
- 🎲ボタンで、校章と印をおまかせで入れる

## 初期値について

- 初期入力の学校名・氏名は、すべて架空のものです。
- 校章と印、区切り線などのオプションは、初期状態では「なし」です。
- レイアウトEを選ぶと、校章と印のサンプルが自動で入ります。

## 技術メモ

- 単一のHTMLファイル(外部ライブラリなし)
- 描画はCanvas(1012×638px。名刺サイズに近い横長比率)
- 出力はPNG
- ブラウザのストレージは使用していないため、再読み込みすると入力内容は初期状態に戻ります

## 利用上の注意

- 架空のキャラクター・学校名での創作、ファンアート、イラスト素材づくりなどを想定したツールです。
- 実在の学校・団体・個人の身分証を装う用途には使わないでください。
- 使用する画像(キャラクター画像、校章、印)の権利は、利用者の責任で確認してください。
